# <u>(DES)CONECTADO</u> 

Idea general: 

El usuario elige un desafío, le da inicio y la app corre en segundo plano hasta que se marque como terminado. No bloquea el uso de redes sociales o aplicaciones, pero sí mide el tiempo de uso de cada una para determinar si lo cumplió o no. En el caso de haberlo completado el usuario gana una cantidad de puntos que puede canjear únicamente en la app. 

**Definir:** qué premios se van a ofrecer en la app, desafíos, duración, tiempo máximo de uso total para que un desafío se considere cumplido, asignación de puntos. 

## **¿Qué tiene que tener este MVP?** 

- App nativa 

- Creación de cuenta y login 

- Participación en desafíos 

- Canje de puntos 

- Perfil de usuario: datos personales, tiempo total de pantalla, historial de logros, canjes. 

- Función de cancelar o interrumpir desafío 

- Calificar desafío 

- Vencimiento de puntos 

- Notificaciones 

## **¿Qué dejar para una segunda versión?** 

   - Foto que refleje el inicio del desafío. 

- Misiones personalizadas. 

- Beneficios por fuera de la app.
